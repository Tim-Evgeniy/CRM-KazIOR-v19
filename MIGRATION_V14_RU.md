# Перенос реальных данных v14

Если вы ещё не вводили реальные заявки, ничего переносить не нужно: v15 начнёт работу с пустой базой и пятью инженерами.

Изменения v14 находились в браузере пользователя, а не в архиве HTML/CSS/JS. Новый сервер не имеет доступа к данным вашего прежнего браузера. Не удаляйте старую папку и профиль браузера до проверки переноса.

1. Откройте прежнюю v14 в том же профиле браузера и по тому же адресу, где велась работа.
2. Войдите супер-администратором, откройте настройки и выполните полный экспорт базы в JSON с вложениями.
3. Распакуйте v15 в **отдельную новую папку**. Не регистрируйте сотрудников и не создавайте заявки до импорта. Остановите сервер v15, если запускали его для проверки.
4. Запустите **IMPORT_V14.bat**. Укажите путь к выгруженному JSON.
5. Импорт допускается только в пустую v15, чтобы не смешать рабочие базы и не перезаписать новые заявки. Перед импортом создаётся контрольная копия. Неподходящий формат отклоняется.
6. Запустите v15. Проверьте число заявок, историю и несколько вложений.

Что сохраняется: пользователи, подразделения, заявки, их сообщения и история, задачи, уведомления, прямые чаты, экспортированные байты вложений до 10 МБ на файл. Если в старом JSON были только имена файлов без байтов, программа не сможет восстановить содержимое из этих имён.

Пять инженеров сохраняют новые номера и индивидуальные пароли v15. Все остальные импортированные учётные записи получают роль сотрудника. Прежние открытые пароли и токены интеграции не переносятся. Исторические WhatsApp-заявки не запускают рассылку на старые номера; каналы настраиваются отдельно.

Для перенесённых сотрудников создаётся закрытый файл `data/IMPORTED_ACCESS.txt` с новыми индивидуальными данными. Супер-администратор выдаёт каждому сотруднику только его данные после проверки личности. Для первого входа в сохранённую историю нужно нажать «Я инженер» и использовать эти логин и пароль — права останутся правами сотрудника. После такого первого входа браузер запомнит кабинет, и дальше сотрудник сможет входить по ФИО без пароля на этом же устройстве.

Ввод совпадающего ФИО на новом устройстве не должен сам по себе открывать чужую историческую переписку. Для входа с другого устройства повторно используйте индивидуальные данные либо привяжите свой WhatsApp.

Импорт не переносит старые настройки почтовых интеграций и токены, служебные журналы доступа к чатам, параметры оформления и демонстрационные почтовые сообщения. Сохраняйте исходный JSON как архив. База v14 и её браузерное хранилище при импорте не изменяются.
