CRM v17 — запуск Windows

1. Полностью распакуйте ZIP в обычную папку, например C:\KazIOR-CRM.
2. Дважды нажмите START_CRM.bat. Окно сервера не закрывайте во время работы.
3. Если Python отсутствует, батник предложит его установку. Нужен Python 3.10 или новее.
4. Браузер откроется автоматически. Адрес по умолчанию http://127.0.0.1:8000.
5. Сотрудник: «Я сотрудник» → ФИО → «Войти». Пароль не нужен.
6. Инженер: «Я инженер» → полное ФИО или логин → пароль KazIOR@2026.
7. Администратор: прежний пароль. При чистой установке — data/FIRST_LOGIN.txt.
8. Для общей работы в локальной сети запустите START_SERVER.bat на одном сервере.
   Сотрудники открывают http://IP-СЕРВЕРА:8000. Одна общая база находится на сервере.
9. Не запускайте index.html двойным кликом и не открывайте HTML прямо из ZIP.

WhatsApp администратора настроен в закрытом файле поставки. Для Telegram, AI
и остальных WhatsApp-номеров откройте «Интеграции». После настройки каналов
перезапустите сервер. Документы доступны отдельной тестовой страницей.
