# KazIOR CRM v17

Единая CRM для заявок, врачей и обратной связи с инженерами. База заявок и переписка сохраняются в SQLite на компьютере с сервером CRM.

## Запуск и обновление

**Новая установка:** распакуйте архив в `C:\KazIOR-CRM`, установите Python 3.10 или новее и откройте `START_CRM.bat`. Для общего сервера используйте `START_SERVER.bat`. Окно сервера должно оставаться запущенным. Нельзя работать через двойной щелчок по `index.html`.

**Обновление v15/v16:** сделайте резервную копию, остановите прежнюю CRM, распакуйте v17 в отдельную папку. Скопируйте прежнюю папку `data` и ваш `server/config.local.json` в новую папку. Запустите v17 с прежним адресом и портом. Миграция сохраняет заявки, администратора и существующие пароли, добавляет Жайнар и сведения об образовании. Обновите браузер через Ctrl+F5. При прямом обновлении v15 сначала выполняется прежняя миграция v16, которая один раз устанавливает общий пароль инженеров.

Для старого экспорта JSON v14 используйте `IMPORT_V14.bat` и `MIGRATION_V14_RU.md`; это отдельный импорт в чистую базу.

## Создать заявку

1. Откройте «Создать заявку». В поле **«Сотрудник KazIOR»** уже стоит ваше ФИО.
2. Напишите, что случилось, выберите категорию и укажите кабинет.
3. Нажмите **«✦ AI ответ»**, чтобы подготовить описание ситуации. Выбранная категория учитывается даже при пустом описании.
4. Укажите телефон для связи, выберите инженера и отправьте заявку.

Доступны категории: Компьютер, Принтер, Сеть, Wi-Fi, Видеонаблюдение, Сервер, ПО / МИС, Телефония, СКС и Другое. Без AI-ключа работают локальные подсказки с уточняющими полями. Заполненные сведения сохраняются в черновике; неизвестные факты не подставляются как состоявшиеся действия. Для свободной генерации по переписке администратор подключает отдельный AI-ключ в «Интеграциях».

Инженер может подготовить ответ тем же помощником в заявке или чате. Предложение можно исправить; оно не отправляется автоматически.

## Где найти новые функции

- **Списки / сотрудники:** поиск по ФИО, отделению и телефону; карточки специалистов с образованием и должностью. Фотография Жайнар загружается с указанного вами адреса onco.kz; для неё нужен доступ к сайту.
- **Почта:** отдельное окно с четырьмя провайдерами. Подключение ящиков, получение писем, поиск, отправка и ответы. Инженер может создать заявку из письма с телефоном сотрудника. Ящик видит только подключивший его пользователь.
- **Корпоративный вход:** Google, Яндекс, Mail.ru, Microsoft на странице входа. Для сохранения своего кабинета сначала привяжите аккаунт в «Моём профиле».
- **Войти с ЭЦП:** выбор файла через NCALayer на своём компьютере. Для завершения входа нужен сервер проверки NCANode. Подробности — `EDS_SETUP_RU.md`.
- **Интеграции:** реквизиты OAuth-приложений, общий WhatsApp-номер или личные каналы, Telegram, AI и ЭЦП. Изменение WhatsApp/Telegram применяется после перезапуска сервера.
- **Документы:** отдельная тестовая страница. Создание служебки, согласование, отказ с комментарием, тестовая подпись и CMS. Примеры и тестовые отметки явно обозначены.

## WhatsApp и Telegram

Предоставленный ключ WhatsApp включён в серверный файл `server/whatsapp.supplied.json` для канала администратора. Проверка состояния этого инстанса 12.09.2026 подтвердила номер **+7 777 971 25 55**. Внешние тестовые сообщения не отправлялись. При запуске CRM повторно проверяет состояние канала.

На личном номере инженера новая заявка `Заявка: не работает принтер` назначается владельцу канала. На общем номере можно указать `Заявка: @elnur не работает принтер`; без логина используется инженер по умолчанию. Один инстанс WhatsApp связан с одним фактическим номером. Для приёма с других личных номеров нужны их подключения.

Продолжение переписки — `KZ-000001 текст ответа` или цитата на сообщение по заявке. Личная переписка без команды, номера заявки и цитаты не превращается в заявку. Новый номер получает отдельный контакт; ФИО кабинета используется после привязки WhatsApp в профиле.

Ответ инженера из CRM возвращается в исходный чат WhatsApp. Входящее сообщение уже уведомляет телефон адресата. Отправить дополнительное WhatsApp-уведомление с номера на этот же номер нельзя: для уведомлений самого администратора используйте CRM, Telegram или другой подключённый канал.

Telegram подключается отдельным токеном бота @BotFather. Пользователь открывает бота по ссылке из профиля и подтверждает свой контакт. Команды: `/new описание`, `/engineer логин`, `/tickets`. Токен WhatsApp не является токеном Telegram.

## Сохранение и резервные копии

Рабочий файл — `data/crm.sqlite3`. База содержит пользователей, заявки, переписку, документы, полученную почту и привязки. Почтовые токены и пароли приложения находятся в закрытой серверной базе, не в данных, отдаваемых браузеру. OAuth Client Secret, AI/Telegram и параметры интеграций — в `server/config.local.json`; предоставленный WhatsApp-ключ — в `server/whatsapp.supplied.json`.

Создать копию: `BACKUP_DATABASE.bat` или кнопка администратора. Восстановить: остановить сервер и запустить `RESTORE_BACKUP.bat`. Перед заменой создаётся копия прежней базы; одноразовые запросы входа отзываются. Конфигурационные файлы сохраняйте вместе с резервной копией отдельно, поскольку они не входят в SQLite.

CRM можно держать на локальном компьютере или на сервере в сети института. Для входа OAuth с рабочих мест нужен зарегистрированный HTTPS-адрес CRM, доступный их браузерам; серверу нужен исходящий Интернет к провайдерам. На одном компьютере поддержан `http://localhost:8000`. Публиковать CRM в Интернет для WhatsApp не требуется.

Проверка хранения 700 сотрудников выполнена; 700 одновременных подключений не испытывались. Подробности проверок — `TEST_RESULTS_RU.txt`; подключения — `CONNECTORS_SETUP_RU.md`.
