# Изменения v17

- Кнопка «Войти с ЭЦП» открывает отдельное окно с выбором ключа через NCALayer. Закрытие окна отменяет выбор. Добавлены серверная проверка через NCANode v3, Docker Compose и START_EDS_SERVER.bat. Вход новым подтверждённым ключом создаёт сотрудника, привязанный ключ открывает свой кабинет.
- Реализованы серверные OAuth-процессы Google, Яндекс, Mail.ru, Microsoft: регистрация обычного сотрудника, привязка своего аккаунта в профиле, отключение привязки, сохранение ролей, защита одноразовых запросов. Ключи приложений настраиваются администратором.
- Новая отдельная страница почты. Gmail API, Microsoft Graph, Яндекс и Mail.ru через IMAP/SMTP с паролями приложения. Получение, локальный поиск, ручная отправка и ответ, отключение ящика, создание заявки инженером. Приватность ящиков и защита повторной отправки проверяются сервером.
- WhatsApp: выбор личного или общего режима одного канала; инженер по умолчанию и явное назначение через @логин. Поля номера, idInstance и собственного ключа, сохранённый ключ отображается только признаком наличия.
- Добавлена Жангербаева Жайнар Ельшатовна, её телефон оставлен незаполненным. Внесено образование всех семи специалистов и учёная степень Муратовой Алмы. Данные доступны в справочнике и карточках.
- Поле «Сотрудник KazIOR», выбор категории для сотрудника и сохранение выбранной категории. AI-черновик получает категорию, кабинет, отделение и введённые факты. Локальные подсказки по всем десяти категориям доступны без AI API.
- Новые таблицы и профили переносятся при запуске без удаления существующих заявок. При восстановлении резервной копии одноразовые OAuth-запросы очищаются.

Для новых внешних подключений нужны реквизиты владельца. Интеграции реализованы в коде, но личные аккаунты, Docker/NCALayer и OAuth-согласие пользователя не могут быть подключены автоматически из архива. Подробности и ограничения указаны в CONNECTORS_SETUP_RU.md, EDS_SETUP_RU.md и TEST_RESULTS_RU.txt.
