CRM КазНИИОиР v17 — заявки, инженеры, почта и ЭЦП

1. Полностью распакуйте архив. Запустите START_CRM.bat.
   Для общего сервера: START_SERVER.bat. Нужен Python 3.10 или новее.
2. Сотрудник входит по ФИО без пароля. Инженер — ФИО/логин + пароль.
   Пароль инженеров новой установки: KazIOR@2026.
   Пароль администратора: data/FIRST_LOGIN.txt (на чистой базе).
3. В «Создать заявку» доступны категория, телефон и помощь в описании ситуации.
4. «Почта» открывает отдельное окно подключения, получения писем и ответов.
   Корпоративный вход настраивается в «Интеграциях».
5. «Войти с ЭЦП» → «Выбрать ключ с компьютера» открывает выбор в NCALayer.
   Для проверки ЭЦП запустите START_EDS_SERVER.bat (нужен Docker Desktop),
   затем включите NCANode в «Интеграциях». Инструкция: EDS_SETUP_RU.md.
6. Предоставленный ключ WhatsApp сохранён на серверной стороне для номера
   администратора. Можно использовать общий номер или личные каналы инженеров.

Порядок обновления прежней базы: START_HERE_RU.md.
Подключение Google, Яндекс, Mail.ru, Microsoft и WhatsApp: CONNECTORS_SETUP_RU.md.

Не открывайте index.html двойным кликом: CRM работает через запущенный сервер.
