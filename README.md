# KazIOR CRM — GitHub Pages DEMO

Это **демонстрационная статическая версия** CRM для показа интерфейса через GitHub Pages.

## Что работает в DEMO

- быстрый вход как администратор, инженер или сотрудник;
- заявки, Kanban, статусы, задачи, чаты, справочник, аналитика и отчёты;
- создание заявок и локальное сохранение в браузере;
- AI-помощник в локальном демонстрационном режиме;
- тестовые документы и тестовая подпись;
- демонстрационная почта;
- интерфейс WhatsApp / Telegram / OAuth / ЭЦП с безопасной симуляцией.

## Что намеренно НЕ подключено

GitHub Pages не запускает Python/SQLite backend. Поэтому реальная общая база, OAuth, WhatsApp, Telegram, почта, ЭЦП и OpenAI API требуют серверной версии CRM. В DEMO эти функции симулируются и **не отправляют реальные данные наружу**.

## Как включить GitHub Pages

1. Создайте новый репозиторий, например `CRM-KazIOR-Demo`.
2. Загрузите **содержимое этой папки в корень репозитория**.
3. Откройте `Settings → Pages`.
4. В `Build and deployment` выберите `Deploy from a branch`.
5. Branch: `main`, Folder: `/ (root)` и нажмите `Save`.
6. Через 1–3 минуты GitHub покажет адрес вида `https://USERNAME.github.io/CRM-KazIOR-Demo/`.

## Демо-вход

На стартовом экране есть три кнопки быстрого входа. Также можно ввести ФИО `Иванова Анна Сергеевна`. Для инженерного входа: `demo-admin` / `demo1234`.

## Сброс DEMO

Данные хранятся в `localStorage` браузера. Очистите данные сайта в браузере, чтобы вернуться к исходному набору.

> В эту версию специально не включены `data/`, SQLite, серверные конфиги, токены, API-ключи и резервные копии. Её безопаснее использовать в публичном репозитории, чем полный серверный архив.
